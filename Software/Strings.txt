HOW TO USE THIS FILE

Each entry starts with a marker line:

    #[042] MainWindow.xaml:196  tooltip on tlbr_Open

Everything after that line, up to the next #[nnn], is the text as it
appears on screen. Change those lines and hand the file back; the #[nnn]
markers are how the changes get put back in the source, so leave them
alone. An entry you do not touch stays as it is.

{1}, {2} and so on are places where the program drops in a value - a file
name, a count, an address. Keep them, and keep them in an order that still
reads properly.

[glyph U+E74E] is an icon drawn in the text. Keep those too.

A blank line immediately before the next #[nnn] is the separator, not part
of the text. Blank lines inside an entry are real - they are paragraph
breaks in a message box.

An underscore in a menu or button caption marks its Alt key: "_File" is
Alt+F. Two in a row prints one underscore.
